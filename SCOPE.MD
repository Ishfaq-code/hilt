# Club Management App — Application Flow

## 1\. User Roles

The application has two main application-level roles:

_

-   User: Can discover organizations, join clubs, create clubs through an application process, and manage organizations they own or serve as an officer of.
    
-   Platform Admin: Can manage the entire application, review club creation requests, moderate organizations, and view application-wide statistics.
    

_

Within an individual organization, users can have different roles:

_

-   Member: Regular user who belongs to an organization.
    
-   Officer: User with additional permissions to manage an organization.
    
-   Owner: User responsible for managing an organization, including its members, events, and information.
    

_

## 2\. Club Creation Flow

_

1.  A user selects Create Organization.
    
2.  The user completes and submits a club creation application.
    
3.  The application is sent to platform administrators for review.
    
4.  A platform admin reviews the submitted application.
    
5.  The admin can either:
    
_

-   Approve: The organization is created and becomes visible on the application's organization discovery page.
    
-   Deny: The application is rejected, and the organization is not created.
    

_7.  Once approved, users can discover and join the organization.
    

_

## 3\. Organization Discovery & Joining

_

1.  A user navigates to the Explore Organizations page.
    
2.  The user browses available organizations.
    
3.  The user selects an organization to view its details.
    
4.  The user can join the organization.
    
5.  Once joined, the user can access the organization's member-facing information.
    

_

Organization Information:

_

-   Organization name
    
-   Description and purpose
    
-   Membership fees/dues
    
-   Club events
    
-   General club information
    

_

## 4\. Organization Management (Owner / Officer)

Users with officer or owner permissions can access an Organization Management Dashboard.

Organization Information Management

_

-   Edit the organization's name.
    
-   Update its description and other organization information.
    

_

Event Management

_

-   Create events for the organization.
    
-   Manage existing organization events.
    

_

Member Management

_

-   View organization members.
    
-   Manage the organization's membership.
    

_

Organization Statistics

_

-   View total member count.
    
-   View overall statistics for the organization.
    

_

These management features are restricted to users who have the appropriate permissions within that organization.

## 5\. Platform Administration

Platform admins have access to an Admin Dashboard to oversee the entire application.

Club Application Review

_

-   View submitted organization applications.
    
-   Approve or deny club creation requests.
    

_

Application-Wide Statistics

_

-   View total organizations.
    
-   View total users.
    
-   View overall application statistics.
    

_

Organization Moderation

_

-   Oversee organizations across the application.
    
-   Perform moderation when necessary.
    

_

Individual Organization Statistics

_

-   View statistics for each organization.
    
-   Monitor individual organization activity and membership.
    

_

## 6\. Main Pages / Dashboards

User-Facing Pages

_

1.  Login / Authentication
    
2.  Main Dashboard
    
3.  Explore Organizations
    
4.  Organization Details
    
5.  Create Organization Application
    
6.  My Organizations
    
7.  Organization Member Dashboard
    

_

Organization Management Pages

_

1.  Organization Management Dashboard
    
2.  Manage Organization Information
    
3.  Manage Events
    
4.  Manage Members
    
5.  Organization Statistics
    

_

Platform Admin Pages

_

1.  Admin Dashboard
    
2.  Club Application Review
    
3.  Application Statistics
    
4.  Organization Moderation
    
5.  Individual Organization Statistics
    

_

## 7\. Overall Application Flow

User registers/logs in → Explores existing organizations or submits an application to create a new one → Platform admin reviews creation requests → Approved organizations become discoverable → Users join organizations → Members access club information and events → Officers/owners manage their organizations → Platform admins oversee the entire system.
